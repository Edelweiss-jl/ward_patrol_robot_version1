## 如何使用及扩展

从项目根目录运行当前程序；模型路径使用 `artifacts/adaptive_artifacts_v1/文件名`。具体入口见 [项目总说明](../../README.md) 和 [实验总览](../README.md)。旧模型不能直接套入新观测空间；源码快照内的旧导入保持原样，需要按当时环境复现。

不要将新实验覆盖到本目录。新建相邻的带版本/日期目录，并记录参数、种子、依赖与评估条件。下方历史说明中的“上一级”和旧根目录路径均指整理前布局；新位置请查 [迁移对照](../../docs/migration/README.md)。

## 原始说明（历史记录）

# 首轮自适应规划归档

这是首轮Q-learning模式选择与自由方向局部候选方案的历史记录，不是最终默认规划器。

训练60回合、种子1000—1059。首轮测试4000—4019暴露走廊退化和部分环形回合绕行；其中固定cruise的环形平均耗时甚至高于A*。所有原始评估及源码快照保留，不删除较差结果。

之后修正墙角必要路点被过早丢弃的问题，改为稳定全局路线跟踪、动态拓扑重规划和安全可见捷径，并重新训练。6000系列保留为FIFO导航诊断，最终组合另用8000系列。模型与数据见上一级 `adaptive_artifacts_v3/` 和 `README_adaptive_patrol.md`。

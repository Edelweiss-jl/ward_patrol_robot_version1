# 电梯统一建模

在地图编辑器右侧展开「电梯统一管理」。每部电梯只需配置一次名称、默认入口宽度和停靠楼层；各层入口通过下拉框关联到这部电梯，无须重复填写编号或服务楼层。

## 建模步骤

1. 点击「新增电梯」，输入名称，勾选停靠楼层，点击「创建电梯」。
2. 在任一停靠层点击「定位入口」，在墙体上放置入口，再在地图弹窗里选定电梯并点击「是」。系统生成本层的候梯点和出梯区域，并在其余尚未定位的停靠层自动生成同位置的入口和关联点。
3. 查看楼层清单。系统会检查各停靠层的入口宽度、车型通行、候梯和出梯净空，以及相关路径，并自动确认通过检查的入口。需要调整时，点击「查看 / 调整」。没有匹配墙体或存在几何冲突时，清单会显示原因，可在该层单独定位。
4. 保存地图新版本，再用该版本准备巡查。

创建入口时在地图弹窗点击「是」，即同时发起确认。通过检查的入口可用于跨楼层路线。新增停靠层时，保存电梯设置会根据已有入口补齐能匹配的楼层，已有确认入口的电梯会自动确认通过检查的入口。移动入口会带动自动关联点，也可独立调整候梯点、出梯区域。修改入口、关联点或本层墙体后，可在属性区点击「在地图上查看入口」重新确认。默认宽度用于之后手动放置的入口，已有入口宽度可在对象属性中单独调整。

已有参考入口时，点击「保存电梯设置」可重新尝试生成待定位楼层的入口。系统按墙体长边方向匹配同一位置的墙，包括以窄高矩形绘制的竖墙。

入口属性中的「入口关联」可选择另一部电梯，适用于把旧地图中原本独立的各层入口归入同一部电梯。同一部电梯每层只能有一个入口。名称可修改，内部关联标识保持稳定。

取消停靠楼层会移除该层属于此电梯的入口、候梯点和出梯区域；删除整部电梯会移除其所有关联入口。可以用编辑器撤销操作，保存之前不会改写已有版本。

## 旧地图兼容

旧地图仍可直接运行。编辑和另存时，原本相同电梯编号的入口转换为同一部电梯；没有共享编号的入口保持独立，不按坐标或名称猜测关联。

如果旧入口的服务楼层配置不一致，迁移会保留原本双方均允许的通行关系，并显示提示。在统一面板明确保存停靠设置后，才使用新的统一停靠关系。仅查看、改本层位置或确认入口不会自动扩大旧版通行范围。

新保存的版本使用 schema 3，包含建筑级 `elevators`、统一的 `served_floors`、按楼层索引的 `landings` 和本层入口的 `lift_id`。已保存的历史文件不作原地迁移。

# 病区巡查机器人项目进度

2026-11-17，按用户提供的已完成清单记录，作为后续开发和汇报的基线。

| 模块 | 已完成内容 |
| --- | --- |
| 地图与版本 | `corridor`、`ring` 已接入版本化地图，另外提供常见医院布局模板。画布、A\* 和 PyBullet 使用同一份米制几何。可重命名地图版本，历史运行保留当时的地图快照。 |
| 装修式建模 | 可以拖框创建楼层范围或病房，边拖边看尺寸，释放后生成四周墙体。病床、医护站、隔墙和家具可从物品栏拖入。支持吸附、旋转、框选复制、`Delete` 删除、`Ctrl+Z` 撤销和悬浮提示。未连接的墙端会用紫色标记。 |
| 门洞与电梯入口 | 点击墙体可选择是否开门洞，确认后才切开墙体。已修复复制病房后门洞未切开、复制高亮残留的问题。电梯入口也附着在墙上，以褐色高光显示，悬浮时才展示详情。 |
| 楼层与视图 | 支持新增、命名、切换、复制和删除楼层。单层画布可缩放、旋转，点击「移动画布」才用左键平移。整栋楼视图会缓慢顺时针旋转，也可手动调整视角和缩放，点击某层可进入单层。 |
| 病房与床位 | 门洞可编辑对应病房编号。病床和床旁服务点共用一套显示名称。床位属性可查看楼层、所属病房和入住状态。选择「已有入住」后可填写患者资料。 |
| 车型与车辆 | 车型和车辆实例各有新增表单与可展开、收起的队列，可从队列查看和修改。车型支持独立保存，删除时检查车辆及当前地图引用。车辆按次新增，可选停车点和红、黄、蓝、绿、紫五种车身颜色，确认后在对应楼层画成圆柱体。初始电量和最低安全电量按实例设置。每个停车点限一辆车。删除车辆后，建模时创建的停车点及其编号仍保留。 |
| 规划与巡查 | 支持按车型预览通行，A\* 同时服务预览与运行。自动测试覆盖门宽对大小车型的影响、PyBullet 门洞碰撞几何，以及 1、2、4 台车执行任务。 |
| 任务管理 | 创建任务时生成唯一编号。可在画布点选床位，也可手输「楼层 / 床位编号」，换楼层会保留已选床位。保留任务模板、周期发布及停留计时、人工确认、MQTT 采样三种服务方式。 |

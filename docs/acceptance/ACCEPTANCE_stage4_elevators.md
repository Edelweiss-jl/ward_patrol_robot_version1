# 阶段 4 电梯跨层与共享通道验收

## 启动

从项目根目录运行。下面的目录和端口用于隔离验收数据。

```powershell
.\venv\Scripts\python.exe -m ward_patrol_web.server --no-mqtt --port 8014 --workspace outputs/stage4-acceptance
```

在另一个 PowerShell 窗口用默认浏览器打开。

```powershell
Start-Process 'http://127.0.0.1:8014/editor'
```

使用日常地图时，继续使用端口 `8013` 和默认 `outputs` 目录，且只保留一份写入同一工作目录的服务进程。开启 MQTT 时沿用阶段 1 的 broker 和体征服务启动流程。可选 `--gui` 打开 PyBullet。

## 双车相反方向验收

1. 在地图版本列表选择「两层电梯验收病区 v1」。一层、二层各有一个停车点和床位，两个入口共用电梯 `E1`。
2. 在一层使用「新增车辆实例」确认一辆小型巡查车 `R1`，使用本层停车点。切到二层新增 `R2`。展开车辆队列并保存车队。两车分别显示在各自楼层。
3. 点击「车型通行预览」。跨层结果显示经过 `E1` 和预计耗时。切换楼层仍能看到对应路段。
4. 点击「准备巡查」，先在任务区创建二层床位任务，在任务设置中指定 `R1`。再创建一层床位任务并指定 `R2`。两项使用停留计时服务。保存时可见任务编号，任务进入待分配。
5. 点击「启动巡查」。两车到各自楼层的候梯点；先放行一个方向。监控显示轿厢停靠层、上行或下行批次、乘车车辆和候梯车辆。移动时显示起点、终点和行程比例。
6. 先乘梯的车完全驶离出梯区域后，另一方向才获准进入。切到相应楼层查看车辆路线。两台车随后分别完成对方楼层的床位任务。
7. 查看「下载事件 CSV」及「下载逐步电梯记录」。`elevator_reserved` 对应到候梯点，`elevator_entry_permitted` 含 `wait_steps` 和 `wait_seconds`，`elevator_occupied` 对应实际乘梯，`elevator_released` 对应驶离出口。反方向的放行步应大于或等于第一辆车的释放步。
8. 在「保存的运行回放」刷新、选择对应运行并加载。移动滑块核对当时位置、批次、占用及等待车辆。回放使用保存的常规快照，逐步电梯位置从下载的 JSONL 查阅。

## 故障和窄通道验收

- 停止或重跑双车样例，按需使用 1 倍速；观察电梯放行前停用，预约释放、车辆在楼层上等待重新规划。恢复后重新派车。入梯后停用，当前乘车仍完成，停用期间停止新放行。
- 在载客运行时点「注入故障」。进度冻结，实际占用保留。恢复后从原进度继续。把目标出口设为堵塞，车辆到目标层仍保留电梯占用，清除后才能驶离。
- 在地图编辑器拖入「单车窄通道」区域，将区域覆盖车辆行径的狭窄段，两端留可避让空间。车辆起点和服务点放在区域外。让两台车从两端驶来，第一台进入后，在「窄通道运行」点「堵塞出口」。已进入车在边界内等待，另一车在外等待。清除后核对 `passage_reserved`、`passage_entry_permitted`、`passage_occupied`、`passage_released` 顺序。
- 在自建地图上，给同一部电梯的各层入口填同一「电梯编号」，为每个入口选择对应候梯点、出梯区域，并勾选互通的服务楼层。入口仍按用户已有样式在墙体上标记。固定步执行用候梯点与出梯区之间的垂直传送模拟轿厢，PyBullet 车辆随乘梯进度更新高度。这一版没有可碰撞的轿厢门或水平穿墙动作。

## 文件与测试

```powershell
.\venv\Scripts\python.exe -m unittest tests.test_stage4 tests.test_stage2 tests.test_runtime -v
node --check ward_patrol_web/static/editor.js
node --check ward_patrol_web/static/furnishing.js
```

- `outputs/stage4-acceptance/runs/<运行 ID>/elevators.jsonl` 从第 0 步开始每个仿真步记录所有电梯。停靠时有楼层；层间移动时有起点、终点、进度及占用。加速改变步数推进速度，暂停不会增长步号。
- 同一目录的 `events.jsonl`、`commands.jsonl` 和 `snapshots.jsonl` 分别保存有序事件、命令生效步和运行回放快照。停车点在快照里分别记录配置预留和车辆当前占用。
- 当前电梯容量为 1。候梯预约在到候梯点后产生；同方向批次包含该次选向时已在队列中的请求，避免新到同向请求让反向车辆无限等待。占用释放后才允许调换批次。候梯时间由仿真步数计算。
- 当前采用已知地图、管理命令与动态车辆间距。动态障碍有限观测归阶段 3。多资源远期时段预约、任务整单优化及 PPO 暂不参与本轮测试。窄通道的侧向避让依赖所配置的两端有可用空间。

阶段 4 验收通过后，回复「阶段 4 验收通过，开始阶段 3」。

# 阶段 2 建图交互修改验收

本次按用户修正实现装修式拖拽建模。阶段 2 整体验收仍需覆盖原任务清单中的其余功能，本文件记录本次建图交互交付。

## 打开新版

从项目根目录执行以下命令，仅验证建图时可关闭 MQTT。若 8013 已有本次测试服务，直接打开页面。

```powershell
.\venv\Scripts\python.exe -m ward_patrol_web.server --no-mqtt --port 8013
```

浏览器打开 http://127.0.0.1:8013/editor 。修改后使用 Ctrl+F5 刷新。此前 8000 上的服务进程需要重启后才会加载新增脚本路由。

## 顺序操作与预期

1. 点击“空白地图”，在画布按住拖出矩形。松开后显示楼层长宽、面积，四周自动出现真实墙体。当前支持矩形楼层范围。
2. 从物品栏拖病床、医护站、床头柜、药品柜、诊疗桌、座椅等到画布。物品显示俯视图形。病床自动关联一个床旁服务点。
3. 拖动物品移动，拖选中物品右下角方块改变尺寸，拖上方圆点旋转。吸附间距可配置，旋转按 15 度吸附。也可通过对象属性填写精确数值。病床移动、旋转及长度调整时，自动服务点跟随。
4. 拖隔墙卡片放入画布，或点击“拖线画隔墙”并拉出隔墙。将门卡片拖到墙上，门自动吸附，墙体形成真实开口。
5. 点击“撤销”恢复前一步。点击“复制楼层”，新楼层继承物品和外墙，对象 ID 重新生成，门、床旁服务点及电梯关联引用更新。
6. 点击“结构与几何校验”，合法布局的 structure 和 geometry 均为空。重叠、越界和无效引用会显示具体问题。编辑中的非法布局仍保留图形，便于修改。
7. 保存新版本，再从版本列表打开，确认物品、外墙、门洞和楼层副本仍在。保存文件位于 outputs/maps/<地图ID>/<版本>.json。

## 立体建模样式更新

网页默认采用斜俯视的立体投影画布，绘制地板厚度、墙体顶面和侧面、病床床架床垫与枕头，以及医护站台面。墙体分段沿用地图编译器生成的实际门洞。可切换平面编辑，物品拖放和旋转仍使用地图米制坐标。

投影与拖拽逆变换、墙体高度方向以及 JavaScript 语法检查已通过。本次浏览器检查工具连接超时，更新后的画面尚未完成视觉复验。网页采用 Canvas 立体投影，PyBullet 继续负责运行时物理场景。

## 立体视角与缩放

- 在立体画布上滚动鼠标滚轮，围绕鼠标指向的地面位置缩放。也可使用画布上方的加号和减号。
- 右键按住拖动调整方向与俯角，中键拖动平移。也可使用左右旋转按钮，或打开“旋转视角”后用左键拖动，再点一次恢复物品编辑。
- 点击“重置视角”恢复初始方向、俯角和适配整层的缩放。需要精确对齐时，可切换平面编辑。

浏览器工具连接超时。脚本检查和模拟画布验证通过，覆盖 21 组方向和俯角下的画布适配及坐标往返，以及缩放锚点、旋转、平移与重置。

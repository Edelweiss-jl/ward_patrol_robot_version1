# 病区巡查工作台

打开 `http://127.0.0.1:8000/` 即进入工作台。原 `/editor` 地址保留为同一工作台的兼容入口，原简易监控移动至 `/monitor`。

## 五个功能分区

| 分区 | 主要工作 |
| --- | --- |
| 地图建模 | 选择地图、编辑楼层和物件、设置电梯、保存地图版本 |
| 车队配置 | 编辑车型、分配车辆楼层和停车点、通行预览、准备巡查 |
| 任务调度 | 选择床位、保存任务、勾选发布、查看队列及调度偏好 |
| 运行监控 | 查看车辆、路线、任务进度和楼层覆盖；暂停、继续及按需展开仿真工具 |
| 历史回放 | 按病区、版本和时间选择记录，查看原地图及任务，拖动回放时间轴 |

宽屏使用左侧导航，窄屏使用顶部导航。每个分区只显示相关工具，共用同一地图画布。切换分区不重新加载地图，也不会自动保存或发布任务。任务备注、床位选择和车队表单会保留；页面刷新前仍需保存需要长期保留的修改。

地图物件仅在地图建模分区可编辑。其他分区仍可缩放、旋转、平移和切换楼层；任务分区支持明确开启床位点选，监控分区支持明确开启障碍位置选取。

## 首次使用

首次进入显示欢迎提示。右上角「使用引导」可随时打开四步流程，点击引导中的按钮可进入对应分区。顶部准备状态显示地图保存、车队配置、任务队列及巡查状态；「下一步」按钮会根据当前配置提示后续操作。

1. 在地图建模选择已有地图，或从模板、空白地图开始。确认床位、服务点、停车点及电梯关系后保存地图版本。
2. 在车队配置确认每台启用车辆都有车型、有效楼层和独立停车点。保存车队，进行通行预览，再准备当前地图。
3. 在任务调度创建任务，点选床位或输入床位编号，保存任务。然后进入任务队列，勾选并发布。保存任务不会直接启动巡查。
4. 在运行监控查看执行结果。下发任务后，系统自动调度机器人和路线。调度参数、故障注入和障碍测试放在折叠区中，按需打开。

有现成地图和车队时，可以直接进入任务调度。地图未保存、车辆引用不存在的车型或停车点、多个车辆占用同一停车点时，准备提示会引导先修正配置。

## 历史记录

列表默认显示已经产生快照的运行，使用病区名、地图版本和时间标记，不直接展示长运行编号。勾选「包含未开始的记录」可查看尚未产生快照的运行。此筛选不删除文件。

加载回放后显示该次运行的地图及状态，任务和运行控件保持只读。离开历史回放分区会恢复进入回放前的实时地图和草稿。尚无快照时会显示空状态说明。

连续加载不同记录时，仍保留最初的实时地图、床位选择及未保存备注。加载过程中离开回放分区会忽略迟到的结果。「事件记录与导出」在回放时导出该次历史运行的完整事件，在实时监控时导出当前运行事件。

## 验证

```powershell
.\venv\Scripts\python.exe -m unittest tests.test_workbench -v
```

覆盖首页及兼容路由、静态资源、历史摘要、准备条件和地图编辑权限。页面验收包括五个分区的显示隔离、引导跳转、任务表单跨分区保留、车队列表、历史空状态，以及只读分区的画布操作。
